RSS Radar · 页面原型

纯静态、零后端、无构建步骤的高保真原型。双击任意 HTML 即可离线打开查看； 所有数据均为 Mock（结构对齐 docs/data-model/examples/）， 页面不发起任何真实网络请求、不依赖任何外部 CDN。

本原型用于确认信息架构、字段清单、交互与响应式效果。技术约束为「纯 HTML + CSS + 原生 JS」，与真实实现阶段（Vite + React + MUI + Tailwind）不同，属有意为之。
1

聚合热榜流

全渠道条目时间倒序流。

  • 排序切换（更新时间 ⇄ 创建时间）
  • 渠道 / 分类 / 时间筛选 + 搜索
  • NEW 徽标、「＋N 源」跨源徽标
  • 每批 20 条懒加载、空态·异常态·加载态
 2

渠道分栏看板

每渠道一张独立卡片。

  • 响应式栅格（桌面 3~4 → 平板 2 → 移动 1）
  • 配置抽屉：展示渠道 / 每卡片条数（默认 10）/ 排序
  • 配置写 localStorage，跨会话生效
  • 渠道健康状态角标（正常 / 失败 / 停用）
 3

分析报告（只做当天）

当天信息全景 + 热点分析。

  • 概要数字卡（总条数 / 活跃渠道 / 热点 / 分类）
  • 热点榜 TOP10（热度分进度条）
  • 分类分布（原生 SVG 饼图）+ 分类分栏
  • 渠道活跃排行、方法论折叠、查看历史趋势入口
 4

历史趋势与回看

跨天趋势 + 回看某天。

  • 原生 SVG 趋势图（1 次请求 data 契约说明）
  • 月度明细下钻（懒加载 + loading 态）
  • 日历回看（有数据 / 无数据 / 已归档三态）
  • 归档区（只读元数据 + 跳 Release 下载）

设计系统

四个页面共用同一套设计令牌（assets/css/tokens.css）与通用组件（assets/css/components.css + assets/js/components.js）， 导航互通、风格一致。设计变量含：主色 / 语义色 / 9 级中性灰阶 / 间距刻度 / 字号刻度 / 圆角 / 阴影 / z-index。
